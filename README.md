# MediaSubMatcher - 中文字幕匹配

MoviePilot v3 插件：扫描 Jellyfin 媒体库，为缺少中文字幕的电影/剧集自动搜索下载中文字幕并落盘，可选 ffsubsync 对齐时间轴。已有中文字幕的自动跳过。

## 功能

- **三源聚合搜索**：字幕库 zmk.pw / OpenSubtitles / assrt.net（射手网·伪站），并行查询聚合
- 按**季集/分辨率/语言**挑选最佳匹配
- 下载解压，按 `<视频名>.<标签>.<后缀>` 命名落盘到视频同目录
- 可选 **ffsubsync 对齐时间轴**（基于视频音轨频谱）
- 对齐产物质量自检（偏移/帧率因子阈值，异常自动回滚保留原字幕）
- 落盘前**正确性判定**（字幕时间轴与视频时长粗比对，拦截错配字幕）
- 触发 Jellyfin 刷库，字幕即刻可见
- 字幕匹配/对齐/拦截状态 PushPlus 推送

## 安装

- **方式一**：MoviePilot → 插件 → 自定义仓库/市场，添加本仓库地址
- **方式二**：下载后手动放入插件目录（`plugins.v2/mediasubmatcher/`）

## 配置说明（插件配置页）

| 配置项 | 必填 | 说明 |
|---|---|---|
| Jellyfin 地址 / API Key | ✅ | Jellyfin 服务器地址与 API 密钥 |
| OpenSubtitles API Key | 可选 | 使用 OpenSubtitles 字幕源需要 |
| assrt.net API Token | 可选 | 使用射手网（伪站）字幕源需要 |
| 字幕库 Cookie | 可选 | 使用 zmk.pw 源需要（需可访问 zmk.pw 的网络环境与 Cookie） |
| ffsubsync 对齐开关 | 可选 | 开启后下载字幕自动对齐时间轴（仅 .srt） |
| PushPlus Token | 可选 | 状态推送到微信（文件 `/config/.pushplus_token`） |

## 注意事项

- **三个字幕源均为可选**，未配置凭据的源自动跳过，不影响其他源工作
- zmk.pw 源的验证码识别依赖 **ddddocr 环境**（未部署该环境时该源自动跳过）
- 只**新增**字幕文件，不删除、不修改任何媒体文件
- 请尽量选择与视频**同版本**的字幕（不同剪辑/帧率的字幕即使经过对齐，也可能存在残留偏差；插件会通过时长比对与对齐质量自检拦截明显错配的字幕）
